# 模型契约诊断与边界加固

2026-10-14。T17 的配置、队列、总结与圆桌链路保持已实现；真实回应质量仍未通过。T12 的全书构建、60 项边界题和 24 项表达题尚未完成，以下开发探针不能替代该验收。

## 本次修改

- 发现提示使用当前片段实际可匹配的字面别名，排除歧义别名；原始完整目录仍用于校验，旧配置保持原输入协议。
- 新发现版本 `character-discovery-v10` 在同一单元最多两次调用内，允许第二次只修失败人物。已通过条目不交给模型重做；场景/片段顺序、目标集合和最终完整单元都重新校验。结构错误回退完整第二次生成，不跳过失败单元。
- 共享身份检查拒绝同场景重复局部键、重复既有 ID，以及跨场景同键的 ID、new/uncertain 状态或匿名状态变化。需要放弃原身份时，只能使用服务器分配的独立键，保留 `uncertain/id=null` 候选；不增加原著知识或 Agent 发布权限。
- 失败检查点也在 `BEGIN IMMEDIATE` 内检查授权并写入，避免删除在检查后先清空数据、旧请求再恢复含引文的修复包。并发回归实际执行来源删除，修复前稳定恢复了已删除数据，修复后检查点保持清空。
- 审查请求显式提供 0 起始 ordinal。纯格式错误只重审原候选；任何语义否决都重新生成，具体否决理由作为数据反馈。全流程仍最多两次生成、两次审查及一次未知回退审查。
- 审查不重复发送两份 claims；预算不足时只裁剪未被引用的可选表达、历史与记忆。问题、身份、本人基线/命题和已引用消息全部保留；必要材料仍超限则明确失败。记录审查输入哈希、字节数和裁剪数量，不改变生成上下文。
- `character-chat-v10` 要求完整正文的非标点内容被断言覆盖，推演明确标为假设；修复了新版本误拒合法沉默的问题。固定未知回退仍须独立审查。
- 对已观察到的明确否定经历措辞，在完整正文检查，不能借 canon/inference/听说/conversation 标签绕过。只有本人 `firsthand` 允许命题以明确第一人称逐字支持整个否定句时才放行；他人引语、相同摘录、另一对象或另一范围的否定都不够。失败进入原有限改写，不静默修改正文。

最后一条是保守词面规则，会误拒部分合理改述；引语识别和条件句识别也不穷尽语义。它不能证明所有无依据正面/负面经历都被阻止，独立模型审查仍有漏检。
