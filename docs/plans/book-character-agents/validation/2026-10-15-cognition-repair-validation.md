# T17 认识变化、条件推演与修复反馈

本次继续处理[六组合开发诊断](2026-10-15-discussion-matrix-validation.md)中的漏审和误拒。T17、T12仍进行中，所有原生报告保持`quality_pass=false`。两个人物仍来自不同书籍的既有摘录构建，不能代表完整书籍的人格或完整题集。

## 版本化改动

- 新生成v13先保留v12并补充标注指引；原生复试仍失败，未把该结果删掉。最终新任务使用独立、精简的v14，明确每种来源类型、假设自身的条件标记和引用、元说明归为conversation、性格不等于历史动作或获知结果。旧配置仍按其保存版本恢复。
- 新审查v9明确：“有没有……才见分晓”是过去认识变化，不能从勇敢或愿意进入推出；允许有性格依据的当前条件选择，不要求原书出现用户的新问题。读者原文只有已进入人物允许上下文的内容才能用于审核。
- 修复反馈保留至多6条有界字段路径/原因和遗漏数量，排除Pydantic原始输入及异常上下文。整次请求仍受既有输入预算限制。
- 原校验正确拒绝把trait/style标成character_belief，但提示错误地说成“把信念变成客观事实”。现分别说明真实来源类型及可用origin；拒绝条件等价，未放宽权限。
- 实际评测入口增加固定case筛选、运行源码哈希及基线/检索项的读者证据。完整题集仍验证六组合，未选题显式记录`not_selected`；聚焦运行不能冒充完整矩阵。

没有增加工作器调用次数、自动续轮、允许知识或房间记忆权限。正文仍经完整断言校验和独立审查后原子发布。
