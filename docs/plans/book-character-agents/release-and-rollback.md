# 人物功能分阶段启用与保留数据回滚

这些是后端进程启动环境变量，不是人物权限、原著校验或秒数设置的开关。仅字符串 `1` 为开启，`0` 或其他非空值关闭；未设置保留现有开发默认开启。修改后必须停止旧后端并重启。表达增强仍默认关闭，不能借此配置绕过 T12 质量门槛。

| 变量 | 能力 | 依赖 |
| --- | --- | --- |
| `OCTOPUS_BOOK_WORLD_ENABLED` | 人物发现、档案修订与表达构建入口 | 主开关 |
| `OCTOPUS_BOOK_SINGLE_CHAT_ENABLED` | 新单聊与人物轮次、主题、总结、记忆重置 | 主开关 |
| `OCTOPUS_BOOK_GROUP_CHAT_ENABLED` | 多人房间创建、加入与生成类操作 | 主开关和单聊 |
| `OCTOPUS_BOOK_AUTO_IMPORT_ENABLED` | 导入自动流程的扫描、调度与重试 | 主开关 |

分阶段可先关闭后三项、启用人物档案，再启用单聊、群聊，最后自动导入。关闭群聊时，按持久化房型识别已有群聊，一人成员的群聊也不会退化为单聊权限。

## 关闭与恢复

```powershell
$env:OCTOPUS_BOOK_WORLD_ENABLED = '0'
```

停止并重启正常后端/桌面应用使新值生效。关闭不会删除数据库、来源、构建、房间、消息或摘要；新生成、重置记忆与新增成员被拒绝。原文读取、已有房间只读历史、停止、取消及禁言/移除等权限撤销仍可用。新导航入口隐藏；已保存房间的深链接保持只读。前端收到当前服务能力前不发送受控写请求，断线重连重新确认。

正常关闭流程排空请求并取消工作器；新进程及工作区切换在关闭状态下恢复旧租约/代数，不调度模型。旧时间配置与原轮次模型/主题快照保留；重新启用后仍需按已有继续/重试规则操作。自动扫描重新启用会补偿已有持久导入意图，不把原任务换成新配置。

```powershell
$env:OCTOPUS_BOOK_WORLD_ENABLED = '1'
```

再重启，并确认设置中的真实模型与秒数仍有效。不要运行删除新表的 SQL，不还原旧库覆盖已有对话。

## 备份与限制

迁移前自动生成的 `pre-*` 工作区数据库备份继续保留。部署或回滚前停止后端再备份整个工作区的 `knowledge` 目录，连同 SQLite WAL/SHM 和来源文件；活跃数据库不要只复制 `.db` 文件。模型配置位于全局 app.db，另行按现有应用备份策略保存，不把密钥写入验证文档。

本开关实现与结构行为测试不证明 PDF 阅读、论文蒸馏和普通书籍问答的全部发布兼容性，也不证明原著人格质量；这些仍属于 T12 的最终操作与质量验收。已实施的只读 TXT、导入控件、保留历史及停止操作记录见发布开关阶段验证。
