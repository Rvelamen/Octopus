# 书籍人物对话

以原著证据构建人物，并在彼此独立的聊天室中进行交流。

## Language

**讨论方式**：free 自由聊天或 topic 主题聊天，决定是否有跨轮保留的主题和目标。它不决定谁发言，也不改变人物知识权限。

**发言方式**：natural 自动选人、directed 定向 @、all 全体提问。每种讨论方式均可使用这三种发言方式。

**讨论快照**：服务端在创建轮次时固定的模式、主题、目标和配置版本。恢复沿用原快照，换题只影响后续轮次，不重置房间记忆。

**书籍**：被导入和管理的一部作品。同名作品不能仅凭名称认为是同一本书。

**来源版本**：某个具体附件经固定解析规则得到的原著文本及定位。译本、修订版或解析结果变化可形成不同来源版本。
_Avoid_：把来源版本简称为人物版本。

**人物构建版本**：从一个来源版本提取并校验得到的人物、知情范围和设定。纠错产生新构建，已发布构建保持固定。
_Avoid_：把人物构建版本与来源版本混用。

**原著知情**：原著支持某个人物亲历、观察、被告知或知道共同背景的状态。读者知道的真相不必然是该人物的知识。

**人物信念**：人物在原著中相信的内容，可以与事实不符，也可以随后被修正。
_Avoid_：把信念直接称为世界真相。

**人物基线**：原著最后明确支持的人物观念、信念和关系状态。聊天室交流不会改写它。

**房间记忆**：人物在本聊天室听到的公开说法与经历的交流。它保留说话者和来源，不升级为原著经历。

**记忆代数**：同一聊天室一次重置之间的交流空间。重置后旧交流不属于当前人物记忆。
_Avoid_：把记忆代数称为书籍或人物版本。

**房间来源绑定**：一个聊天室选定的一部书籍及其固定人物构建。房间可同时选定多部书，但不会合并人物的原著知识。

**跨书群聊**：不同书的人物在同一聊天室交换公开信息。新信息是房间内的听说，人物原著经历与核心观念保持各自依据。

**成员禁言**：人物仍在房间但失去发言权限，包括被点名时的回应。禁言只影响该房间。

**成员移除**：人物不再参与本房间后续交流与发言调度，已有发言和原著档案保留。

**圆桌座位**：某房间内 member_id 与 seat_index 的固定展示绑定。移除后保留空椅，重新加入和重置记忆保留位置；座位不决定知识权限或发言顺序。

**聊天气泡**：人物头顶显示的公开消息投影，与右侧日志使用同一已发布消息。生成时仅展示状态，正文经校验后才公开；气泡不是额外的对话或记忆。

**来源已删除的成员**：其原著材料不可用，因此不能继续回应的房间成员。其他来源有效的成员可以继续交流。

**只读房间**：没有可用来源或被明确关闭的聊天室。已有交流可读，不能继续产生人物回复。
