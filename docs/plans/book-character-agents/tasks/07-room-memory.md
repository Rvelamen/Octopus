# T07 保留房间记忆并支持独立重置

状态：已完成存储、服务、桌面协议和界面链路及阶段验证；真实回忆问答的误拒进入 T12 质量验收，未宣称全书质量通过。阶段：M2。

## 用户可见交付

人物记得本房间之前的交流，重开应用后仍能继续；新房间或重置后的房间从原著基线开始。

## 前置依赖

[T06 与人物进行受原著约束的单聊](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/06-bounded-single-chat.md)。

## 实施步骤

1. 按房间与 epoch 构建可见消息和带来源的记忆摘要。
2. 摘要保留说话者、消息 ID、听说与推演类别。
3. 增加历史加载与重置入口，重置递增 epoch 并清除可检索的旧记忆。
4. 对生成与重置竞争设置发布检查，迟到结果不能回填。
5. 将原著事实/表达素材与房间摘要/最近消息分别组织和计量；借鉴历史预算方法，使用服务端 R 及真实成员身份，不复用跨房间的第三方 dialogue_history。

## 验收标准

- [x] 重启可读到已发布交流；其他房间没有这些记忆。
- [x] 听到某说法不转化为亲历或原著真相。
- [x] 摘要不会覆盖人物核心观念、经历和原著关系。
- [x] 重置后旧消息及摘要不再进入模型上下文。
- [x] 原著构建在聊天、摘要与重置前后保持不变。

- [x] 摘要来源使用 book_summary_sources，同房间同代数且不超过 through_seq。
- [x] 重置原子更新 current_epoch 和成员 state_epoch，next_seq 保持单调。
- [x] 已清空但尚未物理删除的旧消息不能进入上下文，迟到摘要也不能回填。

- [x] 不同书的角色共享当前房间公共历史，但摘要仍保留说话者和 room_hearsay 分类（临时跨书成员契约夹具；公开创建由 T08 交付）。
- [x] 重置清除全体成员的本房间记忆，保留各自来源绑定与原著基线。

- [x] 聊天历史不成为原著表达训练样例或新原著权限，表达索引缓存不共享房间状态。
- [x] 历史压缩保留当前问题及情绪/听说所依赖的已发布消息或带准确出处摘要；表达样例优先让出预算。

## 验证场景

- 两个房间不同说法与重启读取。
- 长对话摘要的来源保持、矛盾说法和原著表不被写入。
- 重置与生成竞争及过期事件过滤。

- 跨房间及跨代数摘要、先后消息引用和旧代数保留时的读取。

- 跨书公共摘要、同名发言身份和多成员重置后旧代数排除。

- 同人物两个房间使用相同表达素材但记忆不同；长历史与素材预算竞争、压缩后说话者/来源不丢失。
