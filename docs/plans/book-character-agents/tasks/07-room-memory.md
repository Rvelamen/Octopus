# T07 保留房间记忆并支持独立重置

状态：首版任务草案，已同步跨书群聊与成员控制。阶段：M2。

## 用户可见交付

人物记得本房间之前的交流，重开应用后仍能继续；新房间或重置后的房间从原著基线开始。

## 前置依赖

[T06 与人物进行受原著约束的单聊](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/06-bounded-single-chat.md)。

## 实施步骤

1. 按房间与 epoch 构建可见消息和带来源的记忆摘要。
2. 摘要保留说话者、消息 ID、听说与推演类别。
3. 增加历史加载与重置入口，重置递增 epoch 并清除可检索的旧记忆。
4. 对生成与重置竞争设置发布检查，迟到结果不能回填。

## 验收标准

- [ ] 重启可读到已发布交流；其他房间没有这些记忆。
- [ ] 听到某说法不转化为亲历或原著真相。
- [ ] 摘要不会覆盖人物核心观念、经历和原著关系。
- [ ] 重置后旧消息及摘要不再进入模型上下文。
- [ ] 原著构建在聊天、摘要与重置前后保持不变。

- [ ] 摘要来源使用 book_summary_sources，同房间同代数且不超过 through_seq。
- [ ] 重置原子更新 current_epoch 和成员 state_epoch，next_seq 保持单调。
- [ ] 已清空但尚未物理删除的旧消息不能进入上下文，迟到摘要也不能回填。

- [ ] 不同书的角色共享当前房间公共历史，但摘要仍保留说话者和 room_hearsay 分类。
- [ ] 重置清除全体成员的本房间记忆，保留各自来源绑定与原著基线。

## 验证场景

- 两个房间不同说法与重启读取。
- 长对话摘要的来源保持、矛盾说法和原著表不被写入。
- 重置与生成竞争及过期事件过滤。

- 跨房间及跨代数摘要、先后消息引用和旧代数保留时的读取。

- 跨书公共摘要、同名发言身份和多成员重置后旧代数排除。
