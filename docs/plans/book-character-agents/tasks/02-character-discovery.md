# T02 手动构建全书人物候选名单

状态：候选构建链路已完成并验证，2026 年 10 月 12 日；真实全书人物召回与身份质量留在 T12 评测。阶段：M1。

## 用户可见交付

用户点击构建人物，看到全书人物候选、别名与待消歧状态，任务进度可查询。

## 前置依赖

[T18 图书馆 TXT 导入与全文来源](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/18-txt-library-source.md)，已覆盖 T01 的前置来源要求。

## 实施步骤

1. 建立构建记录、场景、人物和检查点，服务端固定来源与工作区。
2. 按场景执行人物发现与对白归属，处理跨场景别名候选。
3. 加入后台工作器、有限模型调用和结构化结果校验，阶段失败可重试。
4. 提供构建查询与名单分页，在书目人物页显示处理量和身份冲突。

## 验收标准

- [x] 构建遍历全部来源片段；真实全书人物召回率另行评测。
- [x] 仅提及使用 referenced，不等同参与或知情；本阶段不生成任何知识权限。
- [x] 同名、称呼冲突以及群体/不明身份保留待复核，不强行启用 Agent。
- [x] 候选名单阶段明确显示暂不能聊天，没有可用原著知识。
- [x] 重复请求复用任务；错误、取消、有限重试和手动恢复可见。

- [x] 场景、人物、检查点均带 B；场景片段同时校验来源和构建。
- [x] 别名和参与者使用关系表，同名别名允许歧义；单元内身份键支持跨场景复用。
- [x] 指纹固定来源、模型和策略；后台连接始终绑定创建任务时的工作区。

## 验证场景

- 记录输入的模型替身验证只读取当前来源。
- 别名、同名、匿名人物、仅提及人物与对白说话者不明样本。
- 重复构建请求与单场景模型格式失败重试。

- 跨来源场景片段、同名歧义、构建指纹和连接范围检查。
