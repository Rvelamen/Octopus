# T09 向全体提问并控制可恢复的发言队列

状态：首版任务草案，已同步跨书群聊与成员控制。阶段：M3。

## 用户可见交付

用户向本房间全体人物提问，查看逐人进度，可暂停、继续或停止，断线或重启后不丢失队列。

## 前置依赖

[T08 创建跨书多人房间并进行定向与自然回应](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/08-multi-character-room.md)。

## 实施步骤

1. 固定全体成员快照与每人一个槽位，持久化 cursor 和轮次状态。
2. 实现暂停、继续、停止、超时与预算暂停，发布和推进 cursor 同一事务。
3. 增加租约代数和消息槽位唯一约束，阻止迟到或重复发布。
4. 重连补拉快照与 after_seq 消息；重启后中断轮次由用户继续。提供秒数、当前人物、进度与占位失效的公开快照，供 T16 使用；圆桌中的全体队列联调在 T12 验收。

## 验收标准

- [ ] 全体模式覆盖本轮全体成员，不悄悄只回复少数角色。
- [ ] 无话可说的成员有明确跳过记录，失败角色与剩余队列可辨识。
- [ ] 停止后不启动下一人物，迟到结果不发布，已有消息保留。
- [ ] 重启与断线不会造成重复发言，继续从未完成槽位开始。
- [ ] 重启不会自动产生新模型调用。

- [ ] 队列使用 book_round_slots，唯一约束限定每轮每成员一个槽位及每槽位一条回复。
- [ ] 暂停和 interrupted 仍占用单房间活跃轮次名额，恢复必须取得新租约代数。
- [ ] 消息重复或发布失败不能推进 cursor 或消耗 next_seq。

- [ ] @全体明确记录禁言、移除或来源失效成员的跳过状态，其他书角色继续有限队列。
- [ ] 候选选择与提交两处检查成员授权代数；解禁或重新加入不能恢复旧生成结果。

- [ ] 普通模式默认 60 秒、全体默认 300 秒，使用用户已保存秒数。
- [ ] 运行中修改设置不改变本窗口，用户继续时读取最新值并开启新有限窗口。
- [ ] 时间耗尽暂停并递增租约代数，保留消息及 cursor，不自动续时。
- [ ] 使用单调时钟、秒与毫秒正确转换，暂停和服务中断不累计活动用时。

- [ ] UI 快照包含同一人物/槽位、有效租约和执行窗口，超时或停止后不再返回有效生成占位；T12 验证圆桌与右栏一致及重连不重播旧气泡。

## 验证场景

- 暂停与提交、停止与生成、断线与发布的竞争场景。
- 发布前后崩溃、租约接管和重复事件。
- 人数较多的完整队列、预算耗尽和单人物失败。

- 部分唯一索引、暂停轮次占用、失败发布序号不漂移与继续队列。

- 发言中移除后重新加入的旧授权拒绝，以及剩余队列继续执行。

- 假时钟下的截止瞬间、生成/校验超时、设置变更、暂停后续时和迟到结果。
- 普通/all 模式值选择、累计与窗口用时，以及过短限制的明确暂停反馈。
