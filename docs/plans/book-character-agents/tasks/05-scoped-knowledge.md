# T05 查询人物知道什么并查看原著依据

状态：待实施，已纳入 ChatHaruhi 表达方法适配；当前受限检索用例处于 Red，不代表功能通过。阶段：M2。

## 用户可见交付

用户在人物详情提问某个事实是否为该人物所知，得到允许依据或明确未知；另可查看经审查的原著表达规则、对白样例及其出处。

## 前置依赖

[T03 生成有原著证据的人物档案与 Agent](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/03-evidence-persona-agents.md)。

## 实施步骤

1. 提供服务端绑定人物与构建的受限检索接口。
2. 在允许集合内索引中文别名和文本词项，排序后取证据。
3. 为原始片段建立经过校验的视角材料，避免旁白与其他人物内心随同段泄漏。
4. 提供知识依据预览与未知结果，读者原文查看接口与人物接口分离。
5. 建立独立表达派生集、素材和规范化出处表，指纹包含完整人物范围、安全投影、基线与策略配置；不修改已发布原著表。
6. 从本人安全引文提出表达规则/对白，独立审查说话者、精确子串、事实权限及当前基线相容性，保存构建/取消/重试/预算状态。
7. 提供 CharacterExpressionService/ExpressionContext，按用途和问题选择已审查素材；事实与表达各自检索、分别预览，缺素材保持空结果。

## 验收标准

- [ ] 人物、书籍版本及工作区范围在检索前执行。
- [ ] 无权限、无结果或检索失败均不扩大到全书或其他书目。
- [ ] 中文短人名与情节关键词在固定样本中有预期召回。
- [ ] 返回模型的片段不夹带同段其他人物秘密。
- [ ] 旧信念仅在回顾时标注使用，不替代当前基线。

- [ ] CanonicalScope 必须有固定工作区和完整 B＋character_id；检索联接权限和可见证据后再 LIMIT。
- [ ] FTS 同步新增、更新与删除；不存在可见投影时不读取完整原文。
- [ ] 原著缓存含工作区、书籍、来源、构建、人物和策略，不能共享房间状态。

- [ ] 跨书房间的 CanonicalScope 从发言成员的 B 派生，不从房间假定一个全局构建。
- [ ] 另一书角色的公开说法只能作为本房间听说，不能借用对方 claim/evidence 授权。

- [ ] 表达素材具有同 B＋人物的 accepted 可见依据，原句未被模型改写，发言者经过独立确认；他人说话不能作为本人的表达样例。
- [ ] 表达规则来自已有当前有效 style 依据；标签不新增人格或知识。历史错误信念、已改变关系或未知时序样例不能恢复旧立场。
- [ ] 样例含事实时，运行选择核对本次允许依据/当前基线；素材 ID 不充当事实引用。
- [ ] 表达集用独立状态/检查点，不写入冻结的原著构建步骤；权限、原投影或来源失效时派生素材不可读。
- [ ] 原文投影不足、构建失败或配置缺失均明确展示，不从全书/他人/外部角色包填补，不阻止已可用原著事实检索。

## 验证场景

- 人物仍持错误信念时，不从世界真相标签或其他成员档案获得纠正信息。
- 跨人物、跨书籍、跨构建和跨工作区的权限矩阵。
- 全局高排名干扰文档与允许集合低排名事实。
- 无权限降级、中文短词、同段秘密与证据定位。

- 同一数据库中多书、多来源、多构建与多人物的允许集矩阵；另在两个工作区实例验证连接与缓存隔离。

- 跨书角色不能冒用对方原著依据，公共发言只成为 room_hearsay。

- 原句夹带旁白秘密、他人台词、历史错误信念、跨版本关系、改写引文及高排名无权限样例。
- 当前问题与表达样例包含不同事实时的过滤；零样例、重复素材、租约失效、取消迟到审查与派生集只读发布。
