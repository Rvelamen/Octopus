# T04 纠正人物身份与依据并发布修订版本

状态：已实施并验证，2026 年 10 月 12 日。阶段：M1。

## 用户可见交付

用户可纠正人物别名、合并关系与证据归属，新版人物可用，旧版仍可回溯。

## 前置依赖

[T03 生成有原著证据的人物档案与 Agent](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/03-evidence-persona-agents.md)。

## 实施步骤

1. 提供基于原文证据的修订入口及期望版本检查。
2. 建立修订构建，保留人物 lineage 并重新计算受影响权限和基线。
3. 原子发布修订结果，展示变更与旧版本。
4. 无原文依据的用户设定记录为扩展材料，严格原著运行不采用。

## 验收标准

- [x] 无法用无依据的编辑直接覆写原著事实。
- [x] 合并人物后重新检查对白、信念和知情权限，不只改名字。
- [x] 旧构建保持不可变，人物 ID 与旧作用域不自动改绑；实际房间绑定回归随 T06/T11 完成。
- [x] 并发编辑冲突可见，修订失败不破坏可用版本。

- [x] 修订父构建与新构建必须来自同书同来源，禁止原地重开已发布构建。
- [x] 基线引用通过本人的权限关系校验，跨版本 lineage 不构成授权。

## 验证场景

- 正确别名合并、错误合并拒绝和无依据设定。
- 修订前后人物权限比较与发布失败恢复。
- 读者查看依据和修订差异的操作演示。

- 跨来源修订、重开已发布构建与旧版基线保留。
