# T10 导入小说后自动构建人物并恢复后台任务

状态：首版任务草案，已同步存储约束。阶段：M4。

## 用户可见交付

用户导入小说并启用自动构建，来源准备好后系统自动生成可用人物，失败和重启后可继续。

## 前置依赖

[T03 生成有原著证据的人物档案与 Agent](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/03-evidence-persona-agents.md)。

## 实施步骤

1. 导入 UI 增加资料类型和自动构建选项，意图随书目创建持久化。
2. 工作器等待附件可读，启动时和周期扫描补齐漏排队任务。
3. 使用构建检查点与租约恢复未完成阶段，提供取消与重试。
4. 显示解析与人物构建的独立进度，不阻塞书目使用。

## 验收标准

- [ ] 小说导入默认选择自动构建，其他资料和旧请求保持原行为。
- [ ] 不能在临时上传尚未转为来源时调用人物模型。
- [ ] 创建书目与排队之间崩溃后能补齐任务。
- [ ] 重复启动和相同来源不会重复构建；取消后迟到结果不能发布。
- [ ] 配置缺失、扫描件及抽取失败均有可执行的状态说明。

- [ ] 自动构建意图、来源就绪和检查点均固定工作区；模型阶段不得重读可变化的全局根路径。
- [ ] 同一来源与构建指纹请求复用，已清理的来源不作为可用缓存命中。

## 验证场景

- 附件 pending/completed/failed 和导入排队崩溃窗口。
- 构建阶段恢复、取消、旧租约失效及模型配置不可用。
- 普通论文导入兼容与自动构建端到端演示。

- 来源删除后重导入、跨工作区异步阶段及补偿排队幂等。
