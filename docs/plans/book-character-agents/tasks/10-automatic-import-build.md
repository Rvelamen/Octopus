# T10 导入小说后自动构建人物并恢复后台任务

状态：已完成存储、服务、协议与界面链路及阶段验收（2026 年 10 月 14 日）。阶段：M4。真实全书质量继续由 T12 验收。

## 用户可见交付

用户导入小说并启用自动构建，来源准备好后生成可用人物，再建立经审查的表达素材；两类进度独立，失败和重启后可继续。

## 前置依赖

[T05 人物受限检索及表达素材](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/05-scoped-knowledge.md)，其依赖链已包含 T03。基础自动导入可先在 T03 后实现，T10 完整交付需表达接口就绪。

## 实施步骤

1. 导入 UI 增加资料类型和自动构建选项，意图随书目创建持久化。
2. 工作器等待附件可读，启动时和周期扫描补齐漏排队任务。
3. 使用构建检查点与租约恢复未完成阶段，提供取消与重试。
4. 显示解析与人物构建的独立进度，不阻塞书目使用。
5. 已发布原著上按完整 B＋人物＋表达策略指纹排派生任务，复用有界工作器、检查点和租约；表达阶段独立可取消、重试并受调用预算限制。

## 验收标准

- [x] 小说导入默认选择自动构建，其他资料和旧请求保持原行为。
- [x] 不能在临时上传尚未转为来源时调用人物模型。
- [x] 创建书目与排队之间崩溃后能补齐任务。
- [x] 重复启动和相同来源不会重复构建；取消后迟到结果不能发布。
- [x] 配置缺失、扫描件及抽取失败均有可执行的状态说明。

- [x] 自动构建意图、来源就绪和检查点均固定工作区；模型阶段不得重读可变化的全局根路径。
- [x] 同一来源与构建指纹请求复用，已清理的来源不作为可用缓存命中。

- [x] 原著发布后才生成对应人物的表达集，重复扫描不会重建同指纹素材；模型与安全投影配置固定。
- [x] 表达失败或配置缺失不撤销已发布原著或阻止其受限聊天；UI 明确显示表达依据不足及可重试状态。
- [x] 原著补充引文/样例的提取策略更新产生新构建，不修改已发布权限；外部角色包不自动入原著。

## 验证场景

- 附件 pending/completed/failed 和导入排队崩溃窗口。
- 构建阶段恢复、取消、旧租约失效及模型配置不可用。
- 普通论文导入兼容与自动构建端到端演示。

- 来源删除后重导入、跨工作区异步阶段及补偿排队幂等。

- 原著已发布但表达未排队的崩溃窗口；表达预算耗尽/配置缺失、取消和原著版本更新后的独立恢复。
