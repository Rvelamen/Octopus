# T06 与人物进行受原著约束的单聊

状态：首版任务草案，已同步跨书群聊与成员控制。阶段：M2。

## 用户可见交付

用户从人物卡片开始单聊，获得经校验的角色回复和可查看的依据。

## 前置依赖

[T05 查询人物知道什么并查看原著依据](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/05-scoped-knowledge.md)。

[T15 配置人物聊天室时间上限并持久化](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/15-chat-timeout-settings.md)。

## 实施步骤

1. 创建单成员房间、轮次和有序消息，保存人物及模型策略快照。
2. 用受限原著记忆、当前消息和固定人设构建上下文。
3. 解析候选正文与断言，执行引用权限、支持关系及人设校验。
4. 失败最多重写一次，仍失败使用未知回复；正文在校验后发布。
5. 保存角色身份与来源类别，提供历史读取和依据面板。

## 验收标准

- [ ] 亲历事实能回答，旁白秘密不直接确认。
- [ ] 角色信念、原著支持的谎言、房间听说与推演不会被当作客观原著事实。
- [ ] 校验失败、不可用或超时不发布未经检查的正文。
- [ ] 重复 client_turn_id 不重复生成已完成回复或保存消息。
- [ ] 服务端权限及候选格式错误在 UI 可解释。

- [ ] 首次单聊即建立 epoch、轮次、槽位与消息引用结构，不能等多人阶段才补隔离。
- [ ] 消息原著引用必须匹配真实发言成员及其可见证据；拒绝部分 NULL 的原著引用。
- [ ] 消息、引用、槽位状态和 cursor 同事务提交；当前 epoch 和有效租约是发布前置条件。

- [ ] 单聊也使用 book_room_sources；为以后混聊保留统一的成员来源绑定接口。
- [ ] 槽位记录 member_generation，人物消息带 publish_member_generation，发布时核对当前授权。

- [ ] 新窗口按模式读取用户秒数设置，保存 time_limit_seconds 快照并实施基本超时暂停。
- [ ] 检索、生成与校验都计入上限，不能在超时后发布未知回退或原始候选。

- [ ] 本次对话行为与原著动机分开，涉及价值的行为依据可追溯；情绪只从同 R 的触发消息和本人模式生成，未批准候选不落状态。
- [ ] 普通寒暄和有依据的新情境推演可回应；具体事实与自传不得借 conversation/inference 标签绕过检查。
- [ ] 参数知识诱导与合理问题过度拒答分别做真实模型评测，允许集查询正确不被当作语义零越界证明。

## 验证场景

- 记录实际上下文的模型替身和完整提交到发布路径。
- 伪造依据、遗漏断言、已知秘密、人格诱导与错误前提。
- 校验超时、重写失败、重复提交和用户消息保存。

- 其他成员的可见证据冒用、部分空范围、消息槽位和过期租约。

- 来源绑定缺失、成员授权过期，以及自身来源失效但其他书仍有效时的拒绝。
