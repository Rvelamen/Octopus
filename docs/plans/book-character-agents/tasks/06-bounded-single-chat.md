# T06 与人物进行受原著约束的单聊

状态：已完成存储、服务、协议、单聊界面与阶段验证；完整全书质量验收留在 T12。阶段：M2。

## 用户可见交付

用户从人物卡片开始单聊，获得经校验的角色回复和可查看的依据。

[T05 查询人物知道什么并查看原著依据](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/05-scoped-knowledge.md)。

## 实施步骤

1. 创建单成员房间、轮次和有序消息，保存人物及模型策略快照。
2. 用 CharacterContextBuilder 分区组织固定人设、当前基线、受限原著、经审查表达素材、当前问题/讨论快照及可见房间消息。
3. 解析候选正文与断言，执行引用权限、支持关系及人设校验。
4. 失败最多重写一次，仍失败使用未知回复；正文在校验后发布。
5. 保存角色身份与来源类别，提供历史读取和依据面板。
6. 选择匹配问题/行为的短原著样例，初始最多 2 条、每条 160 码点和 3 条已有表达规则；预留生成/校验预算，容量不足先舍弃样例和无关历史。
7. 保存表达集/素材 ID、策略/模型版本及预算诊断，提供同模型无样例/有样例的小规模对照记录。

## 验收标准

- [x] 亲历事实能回答，旁白秘密不直接确认。
- [x] 角色信念、原著支持的谎言、房间听说与推演不会被当作客观原著事实。
- [x] 校验失败、不可用或超时不发布未经检查的正文。
- [x] 重复 client_turn_id 不重复生成已完成回复或保存消息。
- [x] 服务端权限及候选格式错误在 UI 可解释。

- [x] 首次单聊即建立 epoch、轮次、槽位与消息引用结构，不能等多人阶段才补隔离。
- [x] 消息原著引用必须匹配真实发言成员及其可见证据；拒绝部分 NULL 的原著引用。
- [x] 消息、引用、槽位状态和 cursor 同事务提交；当前 epoch 和有效租约是发布前置条件。

- [x] 单聊也使用 book_room_sources；为以后混聊保留统一的成员来源绑定接口。
- [x] 槽位记录 member_generation，人物消息带 publish_member_generation，发布时核对当前授权。

- [x] 新窗口按模式读取用户秒数设置，保存 time_limit_seconds 快照并实施基本超时暂停。
- [x] 检索、生成与校验都计入上限，不能在超时后发布未知回退或原始候选。

- [x] 本次对话行为与原著动机分开，涉及价值的行为依据可追溯；情绪只从同 R 的触发消息和本人模式生成，未批准候选不落状态。
- [x] 普通寒暄和有依据的新情境推演可回应；具体事实与自传不得借 conversation/inference 标签绕过检查。
- [x] 参数知识诱导与合理问题过度拒答分别做真实模型评测，允许集查询正确不被当作语义零越界证明。

- [x] 表达样例的选择和上下文组装核对同一 CanonicalScope，样例事实限于本次允许依据或当前基线，样例标签/ID 不作为事实授权。
- [x] 当前问题、身份约束、基线及必要事实在预算处理中保留；放不下时明确错误，不能静默丢弃约束或截断样例改变语义。
- [x] 基线也经模型专用投影，不直接复用读者档案原文、全场景或世界真相标签，避免同段秘密绕过知识通道。
- [x] 缺表达素材仍使用有据基线回应，未知表达不编造身份或口头禅；正文事实、人设、情绪及来源校验保持完整。
- [x] 生成诊断不进入其他角色的公共历史，表达失败不会公开原始 token，也不延长秒数窗口。

## 验证场景

- 记录实际上下文的模型替身和完整提交到发布路径。
- 伪造依据、遗漏断言、已知秘密、人格诱导与错误前提。
- 校验超时、重写失败、重复提交和用户消息保存。

- 其他成员的可见证据冒用、部分空范围、消息槽位和过期租约。

- 来源绑定缺失、成员授权过期，以及自身来源失效但其他书仍有效时的拒绝。

- 不同角色的安慰/质疑/分歧表达、原句复读、同一问题零样例与相关样例对照。
- 历史对白导致旧观念复活、样例带来未检索事实、长历史抢占事实/校验预算与过度拒答。
