# T16 新增人物聊天室 Tab 与 3D 圆桌气泡界面

状态：首版任务草案，尚未实施。阶段：M3。

## 用户可见交付

用户从独立“人物聊天室”Tab 进入房间，在左侧林间风格的圆桌中看到各人物坐于固定位置，右侧阅读和发送完整对话。角色生成时头顶显示状态，发布后气泡与消息同步展示，点击角色可 @、禁言或移除。

## 前置依赖

[T08 创建跨书多人房间并进行定向与自然回应](F:/god/project/Octopus/docs/plans/book-character-agents/tasks/08-multi-character-room.md)。

核心界面使用 T08 已有的单聊/跨书房间、成员控制和消息服务，以定向/自然模式完成本任务验收。T09 完成前全体功能显示未启用；其进度与续时控制随后使用同一组件，在 T12 完成整合验收。T12 必须同时等待 T11 与本任务完成。

## 实施步骤

1. 增加独立导航与 /book-rooms 路由、房间切换/创建和图书馆快捷入口，刷新恢复 roomId。未选择房间时显示空态和创建入口。
2. 为 rooms 增加布局版本与容量，为 members 增加 seat_index 及房间内唯一约束；旧房间按稳定 created_at/id 顺序一次性回填，容量覆盖全部成员记录，包括离场者。新房间由服务端分配，移除和重置不重排。
3. 建立 useBookRoom 的统一快照、去重消息和场景公开投影；事件只携带公开身份及消息，不向 renderer 传入私密人格或证据上下文。
4. 复用 Babylon.js 依赖，提取适量圆桌、软垫椅、色板和坐姿基础构件，创建独立 BookRoomScene/Canvas；提供全景、缩放、点击聚焦和二维人物列表。
5. 构建右侧消息、输入、@ 选择和成员控制；连接当前秒数窗口与暂停/停止状态，T09 完成后接全体进度及继续。
6. 实现头顶 DOM 气泡投影、同 message_id 的同步渐显、截断/跳转、重叠处理、历史查看和生成状态取消。
7. 处理小屏、减少动态效果、WebGL 失败与资源释放，完成真实操作验收和生产构建。

步骤 1–4 可先用固定快照进行视觉开发，但此时只是场景样稿；完成真实消息和控制联调后才交付本任务。逐步验收为“可进入房间并落座”→“真实发言与气泡同步”→“控制、恢复和降级完整”。

## 验收标准

- [ ] 独立 Tab 可创建/恢复房间，书目快捷入口和浏览器前进后退定位正确。
- [ ] 同一房间跨书同名人物具有不同 member_id、名牌、书籍标签和固定座位。
- [ ] 刷新、重连、禁言、移除后重返和重置记忆保留座位；离场留下空椅；扩容只在空闲时发生。
- [ ] 首版不限制为 8 名成员；16/32 人仍有独立座位，人数不改变调度覆盖。
- [ ] 生成/校验显示状态气泡，未通过校验的正文不会进入场景或右侧日志。
- [ ] 发布正文在头顶和右侧同一次状态更新出现，使用同 message_id/seq，重复广播不重复发言。
- [ ] 长气泡可跳转完整消息，重叠/视野外有可操作入口；历史加载不批量重播动画。
- [ ] 点击人物可填入 @，禁言包括 @ 在内均不能生成，移除后的迟到结果不能恢复人物或气泡。
- [ ] 窗口超时、停止和 epoch 重置及时清理占位；切换 Tab 不自动停止服务端轮次。
- [ ] 窄屏、键盘、减少动态效果和 WebGL 失败时，消息与所有关键控制仍可使用。
- [ ] 场景卸载后 GPU 与 DOM 资源释放；普通消息不导致整个场景重建。
- [ ] 林间图书馆现有阅读、相机操作与沉思者问答回归正常。

## 验证场景

- 同/跨书 1、4、8、16、32 人，空椅扩容、同名角色 @ 和长中文文本。
- 生成、校验拒绝、发布、重复事件、旧轮次事件、补拉与房间快速切换。
- 发言中禁言/移除/局部来源删除、超时暂停、手动继续和记忆重置。
- 相机旋转/缩放与窗口大小改变，气泡锚点和重叠处理。
- WebGL 初始化失败/上下文丢失、减少动态效果和反复打开关闭场景。
- SQL 内存检查、真实服务临时库迁移/协议检查、前端生产构建与浏览器操作录像/截图。记录实测性能，不用 3D 截图代替交互验收。
