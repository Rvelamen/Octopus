# T01 在书目中准备可定位的全文来源

状态：已实施，2026 年 10 月 12 日完成追加验证。阶段：M1。

## 用户可见交付

用户打开小说书目，可准备叙事全文、查看解析质量，并从任意片段定位到原文。

## 前置依赖

无，可作为第一项开始。

## 实施步骤

1. 新增来源版本与片段的持久化结构，关联现有书目和附件哈希。
2. 在已有附件就绪后分批解析全文，保存页码、规范化偏移、短对白与尾部覆盖。
3. 提供来源准备和分页读取接口；书目详情显示解析状态、质量提示和原文定位。
4. 为无文本的扫描件显示需要 OCR，禁止继续人物发布。

## 验收标准

- [x] 重复准备同一来源得到同一版本，不重复创建片段。
- [x] 超过 100 个片段的样本包含全文尾部，少于 20 字的对白不丢失。
- [x] 页码、片段偏移及引文可回溯，缺失来源返回明确状态。
- [x] 旧 PDF 阅读与普通书目导入照常工作。

- [x] 建立 book_id 到 library_item_id 的稳定映射，不用标题或路径识别书籍。
- [x] 来源哈希和解析结果不可原地修改；不同来源的片段不能通过外键混用。
- [x] 删除已准备来源的书目时先禁用人物来源，保证新结构不阻断既有删除流程。

## 验证场景

- 迁移连接和运行时连接都启用外键，既有迁移与书目删除流程保持可用。
- 临时数据库迁移重复执行与旧书目读取。
- 多页长文本、短对白、重复页眉、空文本页和错误哈希。
- 界面准备来源、查看状态与点击引用的演示。

- 来源版本唯一组合、跨书来源引用与原文不可变检查。
