# 图书馆场景视图

2026-10-10：用户已确认采用 Babylon.js 真实 3D、固定斜俯视镜头与温暖、圆润的微缩图书馆视觉。

## 用户流程

图书馆新增“场景”视图。现有自定义分类对应图书区域，未分类书籍有独立区域。用户能创建区域、修改名称与颜色、为区域放置或移除已有书籍。点击区域后镜头推近书架，并展开书籍选择面板；悬停书本显示标题，点击书本进入阅读。关闭书架返回全景。

## 数据与保存

书籍和分类继续使用现有 library WebSocket API；嵌套分类也展示为区域。书架采用分页，不能只展示现有列表最初的 50 本。分类关系变化实时保存，区域位置保存到当前工作区的 `knowledge/library/.scene-layout.json`。用户点击“保存布置”保存拖动结果。新增书籍、删除分类与旧布局兼容。写入失败保留当前编辑并显示可重试的错误。现有分类 API 的放置操作会将书籍移出原分类，界面必须明确表达“移动”。

## 视觉与交互

使用原创的圆润家具、木地板、彩色地毯、盆栽、柔和暖色灯光和书脊。区域可在布置模式拖动，镜头提供缩放与返回全景。模型由几何体构建，不依赖远端素材。真实书籍不足时保留空书架，不添加虚构书籍。界面提供对应的可键盘操作按钮，阅读文字使用现有 DOM UI。

## 模块边界

- 场景状态模块：分类展开、位置规范化、书籍排序与分页数据。
- Babylon 场景：家具、区域、书本、镜头、拾取和拖动；通过回调报告用户操作。
- React 场景面板：区域设置、书籍管理、选择与阅读。
- 阅读：Electron 调用现有 PDF 窗口，浏览器复用 PDF 页面；缺少附件时给出可理解的提示。

场景和 Babylon 依赖按需加载。卸载、切换视图或隐藏场景时清理或暂停渲染，并适配容器尺寸变化。原有卡片、列表、表格、图谱与聊天功能继续可用。

## 验证

验证配置兼容与书籍排序；运行新增文件的静态检查及前端生产构建；在独立浏览器会话中验证场景渲染、区域展开、书籍分页、区域管理、布局保存和阅读跳转。界面测试使用隔离测试数据，不能修改用户现有图书资料。

## 实施顺序

1. 增加 Babylon 依赖和独立构建分块。
2. 实现场景布局状态与现有书籍 API 的接入。
3. 构建微缩图书馆、区域拖动、书架与镜头动画。
4. 接入区域配置、选书、分页和既有阅读器。
5. 在现有图书馆增加场景入口，完成验证。
